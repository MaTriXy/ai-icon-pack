Install

The pack ships as an Agent Skill. Your agent can search all icons by meaning and add them to your project as SVG, PNG, React or Vue components, or an SVG sprite.

Claude Code plugin (recommended)

Add the marketplace and install the plugin, from your terminal or inside a Claude Code session:

claude plugin marketplace add djtoon/ai-icon-pack claude plugin install ai-icon-pack@ai-icon-pack

Or, inside a Claude Code session:

/plugin marketplace add djtoon/ai-icon-pack /plugin install ai-icon-pack@ai-icon-pack

Then just ask, e.g. "add a regenerate and stop button to the chat input using the AI icon pack". The skill also loads on its own whenever you need icons.

Copy the skill folder

  1. Download ai-icon-pack-skill.zip and unzip it.
  2. Move the ai-icon-pack folder into your skills directory:
# personal: available in every project ~/.claude/skills/ai-icon-pack/SKILL.md # project: commit it so your team gets it too .claude/skills/ai-icon-pack/SKILL.md

Or clone and copy in one go:

git clone https://github.com/djtoon/ai-icon-pack.git cp -r ai-icon-pack/plugins/ai-icon-pack/skills/ai-icon-pack ~/.claude/skills/

Upload to claude.ai or Claude Desktop

  1. Download ai-icon-pack-skill.zip. Keep it zipped.
  2. Open Settings → Capabilities and make sure code execution is on.
  3. Under Skills, choose Upload skill and select the zip.

Ask Claude for icons in any chat and it returns ready-to-use SVG or component files.

Claude API (Agent Skills)

Upload the unzipped skill folder once, then attach it to requests that use the code execution tool:

import anthropic from anthropic.lib import files_from_dir client = anthropic.Anthropic() skill = client.skills.create(files=files_from_dir("ai-icon-pack")) client.messages.create( model="claude-opus-5-5", max_tokens=4096, container={"skills": [{"type": "custom", "skill_id": skill.id, "version": "latest"}]}, tools=[{"type": "code_execution_20250825", "name": "code_execution"}], messages=[{"role": "user", "content": "Give me React components for upload, ai-search and settings"}], )

Any agent that supports SKILL.md

The skill follows the open Agent Skills format: a folder with SKILL.md, a zero-dependency Node script and the SVGs. Copy ai-icon-pack/ into your agent's skills directory (for example ~/.codex/skills/ or your framework's equivalent), or point the agent at SKILL.md.

No skill support? The script works on its own:

node ai-icon-pack/scripts/icons.mjs search "ai chat" node ai-icon-pack/scripts/icons.mjs add chat-sparkle regenerate --out src/icons --format react

Use the icons directly

Download all SVGs (outline, filled and AI gradient), or download single SVGs and PNGs from the gallery above. To build every PNG size (16 to 512px, black, white and gradient) locally:

git clone https://github.com/djtoon/ai-icon-pack.git cd ai-icon-pack && npm install && npm run build # → dist/svg, dist/png, dist/preview.html

What your agent can do with it

One script, scripts/icons.mjs, with zero dependencies, used through the skill:

Search by meaning

search delete finds trash, search ai reply finds chat-sparkle. Synonyms are built in.

Framework-native output

React (.tsx/.jsx) and Vue components with a size prop, plain SVG, or a merged SVG sprite.

PNG at any size

--format png --size 24,48,512 --color "#111" for native apps, email and docs.

AI gradient

Add --gradient to bake in the violet to cyan gradient for AI highlights.

node scripts/icons.mjs add chat-sparkle regenerate stop-generating --out src/components/icons --format react --style both
